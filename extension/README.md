# ChatBridge

在 VS Code / Cursor 的活动栏打开 ChatBridge，通过自己的网关使用微信。支持联系人与群会话选择、接入后历史、文字、图片和文件，以及语音接收、播放和保存。音频发送使用普通文件。

0.2.0 使用固定应用栏与手机式微信导航：默认会话列表，底部切换联系人；点击进入整页对话，左上角返回原列表。搜索、列表位置和会话草稿在当前界面会话内保留。自己的气泡使用深灰底、右对齐和灰蓝细线。回形针发送附件，左下角齿轮打开连接、配对与诊断。

设备通过本机 Windows 用户加密的 `.dpapi` 文件配对，导入后由编辑器 SecretStorage 保存私钥。连接使用 TLS 1.3 双向认证，并核对网关证书指纹；服务器只转发字节。

平台能力来自网关的适配器清单。尚未接入的平台不会显示成已经可用的账号。

当前微信附件依赖客户端后台落盘，可能延迟；界面会分别显示等待、缩略预览和内容就绪。发送的服务器回执不表示对方已读。锁屏运行需要 Windows 用户已登录、微信与网关进程在线；睡眠、注销和关机不能继续实时收发。

构建：`npm ci`、`npm run build`、`npm test`、`npm run package`。
